Introduction

This report analyzes home prices using linear regression. We will examine the relationship between floor size and price, and then extend it to multiple regression by including the number of bedrooms.

Questions of Interest

How are half-bathrooms represented? Why? Do you agree?

- Half-bathrooms are counted as 0.1. This reflects that they add some value but not as much as a full bathroom. This allows for differentiation between full and half-baths. I agree with this representation since it accurately reflects the real-world concept of bathrooms.

Why are the model prediction intervals very wide?

- The model doesn’t have variables like geographical neighborhood, condition of the property, landscaping, and features such as fireplaces and updated kitchens, leading to high variance in predictions.

How is age represented?

- Age is standardized as (year built - 1970) / 10 to center the values and allow for possible quadratic effects.

Why is lot size discretized into categories?

- Realtors categorize lot sizes into bins because small increases in land size affect price differently depending on the range. As explained in the article, a change from 4,000 to 6,000 would hold more weight than a change from 24,000 to 26,000.

Questions of Interpretation

  • Regression Equation:Price = 173.06 + 57.21 * Size
  • Slope (β1): 57.21 - Indicates how much the price increases per unit increase in floor size. So for every 1000 sqft increase, the price increases by $57,210.
  • Intercept (β0): 173.06 - Represents the estimated price when the size is zero. So, the price of a house with zero size is $173,060. Technically you could interpret this as the cost of the land.
  • R² Value: R² = 0.04058 → This means that only 4.06% of the variance in house prices is explained by floor size alone. The adjusted value suggests that a multiple regression model might be more appropriate.
  • Prediction error - RMSE: The root mean squared error (RMSE) is a measure of the differences between predicted values and observed values. In this case, the RMSE is 118.7, which means that the model’s predictions are off by an average of $118,700.

  • Regression Equation:Price = 225.717 + (81.215 * Size) - (28.992 * Bed)
  • Floor Size Coefficient: 81.215 - The price increases by $81,215 for every 1000 sqft increase in floor size. The p-value is 0.0117 which means it is statistically significant in explaining the price of houses.
  • R² Value: R² = 0.136 → The adjusted R² value is 0.136, which is higher than the simple regression model of 0.04058. This suggests that the multiple regression model explains 13.6% of the variance in house prices.
